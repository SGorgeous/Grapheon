Grapheon · user 文件夹
======================

这个文件夹是**多媒体节点的默认本地引用目录**。

怎么用
------
在节点的「源」里填相对地址。**没写协议头**的地址都会自动补上 user/ 前缀：

    pic.png              →  user/pic.png
    video/clip.mp4       →  user/video/clip.mp4
    ../assets/logo.svg   →  往上一层再进 assets（也可以往上走）

写了协议头的原样使用，不补前缀：

    https://…            网页链接 / 在线媒体
    data:…               内嵌的数据（自己拖进来的文件会变成这个）
    file:///…            绝对路径

支持的类型
----------
    图片    png jpg jpeg gif webp svg bmp avif ico
    视频    mp4 webm ogv mov m4v
    音频    mp3 wav ogg oga m4a flac aac
    网页    http://  https:// 开头，或 .html / .htm
    其它    当文件处理：显示一个图标，Ctrl + 左键打开

    （类型是按扩展名猜的。猜错的可以在节点右键菜单里手动改。）

怎么打开
--------
    Ctrl + 左键     打开（和 Word 里的超链接一样）
                    图片 / 视频 / 音频是就地播放 / 显示
                    网页和文件是**新开一个标签页**
    普通左键        仍然是选中 / 拖动节点 —— 不会被链接抢走

为什么用相对地址
----------------
内嵌（data:）会把整个文件塞进 JSON，一份文档几兆很常见，
存档、导出、撤销快照全都被拖累。

相对地址在 JSON 里只占几十个字节，文件留在磁盘上，随取随用。

注意
----
从 file:// 直接跑时，浏览器允许同目录及子目录的本地文件。
但如果把 Grapheon 挪到别的地方，记得把 user 文件夹一起带走。

（这个说明文件本身可以删。）
