# GRAPHEON

极简 · Undertale UI 风格的 **流程图 + 思维导图** 工具。

**双击 `index.html` 用浏览器打开即用** —— 零构建、零依赖、不联网。

---

## 风格

纯黑底 + 白色方框 + 红色像素心光标，选中项变黄并冒出一颗红心，
底部是带打字机效果的 `* 对白框`。只有黑、白、黄、红四种颜色。

### 字体：GNU Unifont

全站（含 canvas 与 DOM）都用系统里装的 **Unifont**，字体栈
`Unifont, "GNU Unifont", "Courier New", Consolas, "Microsoft YaHei", monospace`——
没装也能跑，只是失去点阵质感。

Unifont 是按 **16px 点阵网格**设计的（实测 16px 时 ASCII 恰好 8px/字、CJK 16px/字），
所以字号必须取 16 的整数倍，否则会被重采样成糊的：正文 `16`，根节点 / 面板标题 / 导出落款 `32`。
它**只有 Regular 一个字重**，所以全局不使用 `bold`（合成粗体会糊），层级改用「字号 + 颜色」表达。

> 显示缩放不是 100% 时（比如 150%），字号会落在非整数倍设备像素上，点阵会被抗锯齿柔化——
> 这是所有点阵字体在 HiDPI 下的通病，没有干净的解法。

### 为什么是普通脚本而不是 ES module

模块之间共享同一个全局作用域（浏览器里所有经典脚本共享全局词法环境），
所以**双击 `file://` 直接打开就能跑**。ES module 在 `file://` 下会被 CORS 拦掉，
想保留「双击即用」就必须放弃 `import`。加新模块只要在 `index.html` 里补一行 `<script src>`。

### ⚠ 两个必须记住的约束

**1. 加载顺序 = 依赖顺序。** 函数声明只在**自己那个脚本**里提升。所以
`onclick = saveFile` 这种「加载期就把函数当值取出来」的写法，要求 `saveFile` 所在模块
必须**先加载**；否则那一行会抛 `ReferenceError`，而且**该脚本后面的所有代码一起不执行**。

> 这个坑真踩过：`ui/toolbar.js` 曾排在 `app/document.js` 前面，
> 结果 `onclick = saveFile` 抛错，后面的导出 / 居中 / 帮助三行绑定全部没执行——
> 四个按钮一起失效。现在 `toolbar.js` 排在最后、且一律用箭头函数包一层（点击时才解析），
> 测试里也有专项断言（A02/A03）盯着每个按钮。

**2. 下载只有一条路径。** 保存 JSON 和导出 PNG 都走 `core/util.js` 的 `downloadBlob()`，
所以测试里换掉这一个函数就能同时覆盖两者。

## 操作

### 方向生成（选中节点后）

**按方向键或 WASD，就在那个方向长出新的节点**，自动连好线并进入改名状态。

| 按键 | 流程图（空间方向） | 思维导图（结构方向） |
|---|---|---|
| `→` / `D` | 在右边生成 | 生成**子节点** |
| `←` / `A` | 在左边生成 | 生成**父节点**（插在当前节点与它父节点之间；选中根节点时新节点成为新根） |
| `↑` / `W` | 在上边生成 | 生成**前一个兄弟** |
| `↓` / `S` | 在下边生成 | 生成**后一个兄弟** |

流程图里会自动避开同一行/列上的已有节点，连按同一方向能拉出一条不重叠的链。

### 其它

| 按键 | 作用 |
|---|---|
| `Tab` | 添加子节点（等于思维导图里的 `→`） |
| `Enter` | 添加兄弟节点（等于思维导图里的 `↓`） |
| `Ctrl` + 方向键 | **只跳转选择**，不新建 |
| `F2` / 双击节点 | 重命名（`Shift+Enter` 换行） |
| `Delete` | 删除节点及其所有子孙（根节点不可删） |
| `Space` | 折叠 / 展开子树 |
| 直接打字 | 覆盖文本重新命名（`w/a/s/d` 已让给生成节点） |
| 拖拽空白 / 中键拖 | 平移画布 |
| 滚轮 | 以光标为中心缩放 |
| `Shift` + 拖拽空白 | 框选 |
| 双击空白 | 新建一个自由节点 |
| 拖拽节点边缘方块 | 拉出连线到另一个节点 |
| `Shift` + 点击两个节点 | 快速建立连线 |
| 双击连线 | 编辑连线标签（如「是 / 否」） |
| 右键 | 菜单：形状（矩形 / 圆角 / 菱形 / 椭圆）、删除等 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |
| `Ctrl+S` / `Ctrl+O` | 保存 JSON / 打开 JSON（也支持拖文件进来） |
| `Ctrl+E` | 打开导出面板 |
| `Ctrl+L` | 重新整理布局 |
| `Ctrl+A` | 全选 |
| `1` / `2` | 切换 思维导图 / 流程图 |
| `H` / `?` | 操作指南 |

## 导出

顶栏「导出」按钮或 `Ctrl+E` 打开面板：

- **导出范围**（按当前选择动态启用）：全部节点 / 仅选中的节点 / 选中的子树。
  面板底部实时显示「将导出 N 个节点 · M 条连线 · W × H 像素」。
  连线只保留**两端都在导出范围内**的，不会拖出线头。
- **标题**：填了就会以 32px 白字画在图片**左上角**，过长自动截断加省略号；留空则不画。
- **文件名**：默认 `grapheon-YYYY-MM-DD`，打开时自动全选。自动清理 Windows 非法字符，
  空值兜底 `grapheon`。

文件名 / 标题 / 上次选的导出范围都会记住。输出固定 2× 分辨率，带白框、
左下角品牌水印和右下角日期。`Enter` 导出 · `Esc` 取消。

## 新建

顶栏「新建」是菜单：**空白文件**（一个中心节点，可以直接按 Tab 开始长）/ **示例文档**。
注意它会覆盖当前内容与自动存档。

## 扩展

### 加一个主题

1. 在 `src/core/theme.js` 的 `THEMES` 里加一项，`canvas` 的键就是画布用的颜色：

   ```js
   mono: {
     label: 'Mono',
     canvas: { bg:'#000000', white:'#ffffff', yellow:'#ffffff', red:'#ffffff',
               gray:'#9a9a9a', dim:'#5a5a5a', grid:'#141414' }
   }
   ```

2. 调 `applyTheme('mono')` 即可 —— 它会同时改画布调色板 `C` 和 CSS 变量，
   并存进 localStorage，下次打开还是它。

调色板只有这一处定义：CSS 变量名与 `THEME_VARS` 一一对应，所以 DOM 和 canvas 永远一致。
按钮悬停的像素心、鼠标红心、画布上选中节点的红心**都是 `--r` 驱动的遮罩/填充**，会一起变色。
如果新主题还要改布局（间距、边框粗细），再复制一份 `styles/theme-undertale.css` 即可。

### 改快捷键

运行时：

```js
GP.keys.bind('ctrl+d', 'node.delete');   // 改绑（同一个动作只保留一个键，旧键会自动释放）
GP.keys.unbind('w');                     // 解绑
GP.keys.reset();                         // 恢复默认
GP.keys.rows();                          // 列出所有绑定（带中文标签，可直接喂给设置面板）
```

改默认值就编辑 `src/interact/keys.js` 里的 `defaultBindings()`。
加新动作：往 `ACTIONS` 里加 `{ label, group, run, overlay? }`，再给它绑一个组合键。
组合键 id 由 `comboOf()` 归一化：`'tab'`、`'ctrl+shift+z'`、`'space'`、`'arrowleft'`、`'?'`…
（单独的 `Shift+w` 会归一成 `'w'`，所以误按 Shift 不会让快捷键失灵。）

### 加新菜单

`src/ui/menu.js` 的 `showMenu(x, y, items)` 是通用的，`items` 是 `[标签, 快捷键提示, 回调]` 或 `'hr'`。
右键菜单和「新建」菜单都是它的调用方。

## 测试

```bash
node tests/run.mjs          # 在真实 Edge 里跑 161 项断言；退出码 0 = 全过
node tests/run.mjs --keep   # 保留临时页面，方便手动打开看控制台
```

覆盖范围：架构（模块确实分开了、`GP` 扩展点存在、**加载期无未捕获错误**）、
顶栏装配（11 个按钮都绑了处理函数、**每个点下去都真的有效果**、保存走统一下载通道）、
字体与主题（Unifont 实测度量、换主题后画布与 CSS 变量同时变）、
核心（布局无重叠、正交布线、命中测试、序列化往返）、
方向生成（四个方向的空间/结构语义、兄弟前后顺序、插入父节点、对根按 `←` 产生新根）、
快捷键表（组合键归一化、改键/落盘/重载/解绑/重置、浮层屏蔽、输入框保护）、
鼠标状态机（拖拽、拉线、框选、平移、双击、滚轮、右键菜单）、
新建菜单（空白 / 示例 / 点别处收起）、导出（三种范围与连线裁剪、标题画到左上角且过长截断、
文件名净化、真产出 PNG）。

> **运行器会同时收集三种错误**：`Runtime.exceptionThrown`（未捕获异常）、
> 注入在 `<head>` 最前面的 `window.__loadErrors`（加载期错误），以及控制台 error 日志。
> 只收控制台日志是不够的——未捕获异常根本不走那条路，
> 所以曾经在「保存/导出已经坏了」的情况下仍然报绿。浏览器 profile 每轮都是全新的，
> 否则上一轮留下的 localStorage 会让断言互相污染，出现「单独跑能过、连着跑就挂」的假失败。
