* 操作指南

— 快速生成（选中节点后）—
方向键 或 WASD在「该方向」新建节点，并自动连好线
　├ 流程图空间方向：上 / 下 / 左 / 右 直接摆放，自动避开同一排的已有节点
　└ 思维导图结构方向：→ 子节点　← 父节点　↑ 前一个兄弟　↓ 后一个兄弟
Tab添加子节点（等于思维导图里的 →）
Enter添加兄弟节点（等于思维导图里的 ↓）
Ctrl + 方向键只跳转选择，不新建节点
— 编辑 —
F2 / 双击节点重命名（Shift+Enter 换行）
直接打字覆盖文本重新命名（w/a/s/d 已让给生成节点）
Delete / Backspace删除节点及其所有子孙（根节点不可删）
Space折叠 / 展开子树
— 导航 —
拖拽空白 / 中键拖平移画布
滚轮以光标为中心缩放
Shift + 拖拽空白框选
双击空白新建一个自由节点
Esc取消选择 / 关闭浮层
— 连线 —
拖拽节点边缘方块拉出一条连线到另一个节点
Shift + 点击两个节点快速建立连线
双击连线编辑连线标签（如「是 / 否」）
右键节点/连线打开菜单：形状、删除等
— 文件与视图 —
顶栏「新建」菜单：空白文件 / 示例文档（会覆盖当前内容）
Ctrl+Z / Ctrl+Shift+Z撤销 / 重做
Ctrl+S / Ctrl+O保存 JSON / 打开 JSON
Ctrl+E打开导出面板（选范围、填标题、改文件名）
Ctrl+L重新整理布局（思维导图自动排版）
Ctrl+A全选
1 / 2切换 思维导图 / 流程图
H 或 ?开关本帮助
* 关闭：按 H / Esc，或点击此框外任意处。
