* 操作指南

— 快速生成（选中节点后）—
方向键 或 WASD在「该方向」新建节点，并自动连好线
Tab添加子节点（落在右边）
Enter添加兄弟节点
Ctrl + 方向键只跳转选择，不新建节点
— 连线 —
点选连线选中它（节点选择被清掉），两端出现可拖的手柄
拖拽端点手柄把这一端取下来，接到别的节点上；松开在空白处 = 取消
E / 右键「节点样式…」节点样式面板：字号 / 字体 / 字色 / 外框色
拖节点右下角手柄自由调整节点尺寸；面板里可一键恢复自适应
拖拽已选中的连线拉出一个拐点，自由改变走向；拉成直线会自动收掉
拖拽拐点方块 / 双击拐点移动它 / 删掉它
右键连线「在此添加拐点」在指定位置插一个拐点；「清除全部拐点」一次清完
E / 右键「连线样式…」打开样式面板
　箭头无箭头 / 单向箭头 / 双向箭头
　线型实线 / 虚线
　走线正交折线 / 曲线（每条线各自独立）
　标签连线上的文字（如「是 / 否」）
拖拽节点边缘方块拉出一条新连线到另一个节点
Shift + 点击两个节点快速建立连线
双击连线快速改标签
— 编辑 —
F2 / 双击节点重命名（Shift+Enter 换行）
拖节点右下角手柄自由调整节点尺寸（右键可「恢复自适应尺寸」）
右键节点「连线端点吸附…」把某条连线的这一端钉在上/右/下/左任意一条边上；默认是「自动」
直接打字覆盖文本重新命名（w/a/s/d 已让给生成节点）
Delete / Backspace删除选中的节点（连同子孙）或选中的连线
Space / 右键「折叠子树」折叠子树（整棵子孙真的会藏起来）
点节点上的数字角标展开（角标上写的就是被藏起来的子孙数量）
— 导航 —
拖拽空白 / 中键拖平移画布
滚轮以光标为中心缩放
Shift + 拖拽空白框选
双击空白新建一个自由节点
Esc取消选择 / 关闭浮层
— 程序化节点 —
右键空白处 →「新建 ▶ 程序节点」建一个程序节点（双线外框 + 左边 ▶）
右键任意节点 →「转成程序节点」把普通节点变成程序节点，或转回来
从程序节点拉线到目标算符就叠加到目标上（外观 / 形状 / 位置 / 数值）
把线连到「分组」上算符落到组内每一个节点上（套娃会一路挖到底）
把程序节点连到另一个程序节点改的是它的操作数 → 链式累加（+3 再 +4 就是 +7）
多个程序节点指向同一目标按连线先后依次累加，+8 再来个 +4 就是 +12
选中程序节点按 E面板里选「作用 / 项目 / 方式 / 数值」
被作用的目标右上角出黄点；数值型的右下角显示累计结果
删掉程序节点目标立刻复原（算符从来没写回节点本身）
— 分组 —
选中多个节点 → Ctrl+G成组（也可以右键空白处或用菜单）
拖分组标题栏 / 边框整体搬动这个框和组内所有节点，相对位置不变
拖分组框右下角手柄自由调整框的大小（这是下限；成员顶出去时框会自动长大，成员回来不缩）
把节点拖进框 / 拖出框自动收纳成成员 / 自动移出
双击分组标题 / F2给分组改名
选中分组后有 4 个端点可以从分组拉线到节点，也可以把线连到分组上
右键空白处 →「在此新建空分组框」先画一个空框，再往里拖节点；空框不会消失
右键分组改名 / 端点吸附 / 加节点 / 换颜色 / 收缩到成员 / 解散
把分组拖进另一个分组套娃；父框自动包住子框，拖父框时子框和里面所有节点一起走
Shift 点分组标题分组多选（追加 / 取消）；可以和节点混选
拖动任一个选中的东西选中的分组和节点一起走
选中多个分组按 Del一次解散全部（成员和连线都留着）
多选时只高亮，不给端点和缩放柄；只选中一个分组时才出
右键分组 →「把选中的加入」把选中的节点或另一个分组塞进去
点击嵌套框最内层先接住；只有标题栏和边框那一条能抓
解散父分组只拆外面那层，子分组和成员都留着
选中分组按 Space / 右键「折叠分组」组内后代藏起来，框留着；标题右边的角标点一下就展开
折叠一个节点后内容被藏光的分组框也一起消失（不留空框）；空分组不受影响
选中分组后按 Del解散分组（只拆容器，成员和连线都留着）
— 文件与视图 —
顶栏「新建」菜单：空白文件 / 示例文档（会覆盖当前内容）
顶栏「排版」按树形把节点摆一次（一次性操作，之后可以随便拖）；摆完分组框会自动重新贴合自己的成员
Ctrl+Z / Ctrl+Shift+Z撤销 / 重做
Ctrl+S / Ctrl+O保存 JSON / 打开 JSON
Ctrl+E打开导出面板（选范围、填标题、改文件名）
Ctrl+L按树形排版
Ctrl+A全选节点
H 或 ?开关本帮助
* 关闭：按 H / Esc，或点击此框外任意处。
