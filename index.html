* 操作指南

公式（{=…}）
节点正文里写 {=表达式}，变量名直接写，不用再套花括号。出错显示 [公式错误]，不会崩。
算术+ - * / % ^ 和括号　{=单价 * 数量}、{=2 ^ 10}
比较= <> < > <= >=　{=数量 > 10}
逻辑&& || !　还有 AND / OR / NOT
拼文本& 或 CONCAT　{=姓 & 名}
条件{=IF(数量 > 10, 批发价, 零售价)}
统计SUM AVG MAX MIN COUNT COUNTA
数字ROUND INT FLOOR CEIL ABS SQRT POW MOD SIGN
文本LEN CONCAT UPPER LOWER TRIM LEFT RIGHT MID REPT TEXT VALUE
列表 / 地图用点取　{=名单.0 & 名单.1}、{=配置.单价 * 2}
— 最常用的 —
双击空白新建一个节点
双击节点改名（写 {名字} 就能引用变量）
拖节点边上的空心环拉一条连线到别的节点上
选中节点 + 方向键往那个方向新建一个，并自动连好线
拖空白 / 滚轮平移 / 以光标为中心缩放
Delete删掉选中的节点、连线或分组
Ctrl + Z撤销（Ctrl + Shift + Z 重做）
顶栏「记录」看这次会话里做过的每一件事，可以按分类筛、复制、导出 txt
H 或 ?开关本帮助
— 有两处和 Blender 不一样，原因在这 —
Shift + A → Ctrl + ABlender 的「添加菜单」是 Shift+A，但本应用的按键归一化
会丢掉单独按下的 Shift（防误按）—— Shift+A 会被当成 A（全选）。
所以改 Ctrl+A。同理「生成节点」从 Shift+方向键改成 Ctrl+方向键。
其余都对上了A 全选 / Alt+A 取消 / Ctrl+I 反选 / X 删除 / F 连接 /
N 侧栏 / Home 看全部 / Ctrl+G 打包 / Ctrl+Alt+G 解组 / Tab 进出组 / F2 重命名
— 生成节点 —
方向键 / WASD在「该方向」新建节点并自动连线
Tab / Enter加子节点 / 加兄弟节点
Ctrl + 方向键只跳转选择，不新建
右键空白 →「新建」文本 / 图片 / 表格 / 空组 / 变量 / 外观 / 程序组 / 嵌入
— 连线 —
点选连线选中它，两端出现可拖的手柄
拖端点手柄把这一端取下来接到别处；松开在空白处 = 取消
Shift + 点两个节点快速建立连线
拖拽已选中的连线拉出拐点；拉成直线会自动收掉
双击连线 / 右键连线改标签 / 改箭头、线型、走线、拐点
E打开选中东西的样式面板
— 节点 —
拖右下角手柄改尺寸；右键可「恢复自适应尺寸」
普通节点四条边各有一个空心环那是连接端点，只负责连线，不参与求值
空环 / 实心点 / 方块空心环 = 连接；实心点 = 数据进出；方块 = 拖动改边或连到别的节点
双击端点方块改端点的编号和标签（连接端点没有编号）
右键 →「外观」形状 / 样式 / 染色 / 透明度 / 自定义描边 / 角标
右键 →「结构」子节点 / 兄弟 / 分组 / 折叠 / 优先级（滑条+填空）/ 条件隐藏
右键连线 →「线宽…」连线的粗细（滑条 + 填空）
右键分组 →「效果 ▶」分组也能挂染色 / 透明度 / 描边 / 角标 / 条件隐藏
Tab / 右键「折叠子树」把子孙藏起来；点角标上的数字展开
— 分组 —
Ctrl + G把选中的东西成组
拖进框 / 拖出框自动收纳 / 自动移出
双击分组标题选中组内所有节点；三击选中外框本身
拖分组标题栏连同组内所有东西一起搬
把分组拖进另一个分组套娃；拖父框时子框和里面所有节点一起走
右键分组改名 / 换颜色 / 收缩到成员 / 设为程序组 / 连接（端点） / 解散
— 端点（连接点）—
端点分三类输入（线进来）/ 输出（线出去）/ 连接（只管连线，没有 ID 和标签）
节点默认四向上右下左各一个，位置在边的中点
分组默认四向四条边各一个连接端点（画成空心环）
右键 →「连接 ▶」列出现有端点（点它就地改标签）＋ 加一个 / 删掉最后一个
「端点 ID…」纯数字，不能重复，决定同一条边的汇合顺序
「恢复默认端点」把端点搞乱了就按它 —— 回到四向中点
拖端点沿边滑动改位置；拖到别的边就换边
从端点拉线 / 拖线改接拉新线；把已经连好的线从 A 端点拖到 B 端点
删端点不删边挂着的线回落到默认端点，不会静默删数据
端点跟着节点走位置存的是「哪条边 + 边上的比例」，挪 / 缩放节点时自动跟着，不用手动对齐
老存档没配过端点就是默认四向，和以前完全一样
分组和节点是同一套结构一样（ports），能改的东西也一样
跨层引用引用的是输出端点的值，写法 {组名.输出名}
— 变量节点：六种类型 —
单一变量填什么就是什么，数字和字符串都行。引用写 {名字}
列表任意长度，默认 0 1 2。引用写 {名字.序号}（序号从 0 开始）
地图key 索引 value。引用写 {名字.键}
滑块起点 / 终点 / 步长都是浮点数，拖动圆点实时改值
勾选 / 条件勾中的拼成一串 / 输入为 1 才把所填的值放出去
切换类型右键 →「数据 → 类型」，或样式面板里那排「控件」
每一格都能写 {变量}列表每一项、地图的键和值、滑块的上下限都算
嵌套引用{a.{b}}、{{a}.{b}}、{a.{b.{c}}} 都行
想打出字面的 {name}前面加反斜杠：\{name}
作用域全局零连线随处可用；局内要么在下游，要么把变量连到一个分组
— 外观节点 / 程序组 —
从外观节点拉线到目标算符就叠加到目标上（外观 / 形状 / 位置 / 数值）
把线连到分组上算符落到组内每一个节点上
外观节点连外观节点改的是它的操作数 → 链式累加
程序组 = 组内变量 + 运算 + 输出组外用一个变量节点指向它，就取到组内算出来的值
输出节点声明本作用域的输出；一个作用域只有一个生效
跨层取值写 {嵌入节点名.输出名}
删掉外观节点目标立刻复原（算符从来没写回节点本身）
— 多媒体节点（图片 / 视频 / 音频 / 网页 / 文件）—
源可以写三种相对地址（pic.png → 自动补 user/）/ 网页链接（https://…）/ 内嵌数据（拖进来的文件变成 data:）
user/ 在哪和 index.html 同级的文件夹。写 pic.png 就等于 user/pic.png；写 ../assets/x.svg 是往上走一层 （./ ../ 开头的**不**补前缀）
为什么用相对地址内嵌会把整个文件塞进 JSON，一份文档几兆很常见 —— 存档、导出、撤销快照全被拖累。相对地址只占几十个字节
右键 →「外观 ▶ → 媒体」换源… / 类型 / 打开源 / 播放
顶栏 user/打开放素材的那个文件夹（浏览器里列出内容， 同时把完整地址复制到剪贴板 —— 粘进资源管理器地址栏就能用）
加节点去哪了顶栏那个「插入」删了 —— 画布空白处右键 →「新建」 是它的真超集（还多表格 / 空组 / 广播 / 外观 / 程序组）。Ctrl + A 弹同一个菜单
类型是自动判的按扩展名。判错了在「媒体 → 类型」里手动指定，或者交回自动判定
Ctrl + 左键打开源（和 Word 里的超链接一个习惯）。 普通左键仍旧是选中 / 拖动，不会被链接抢走
点一下视频 / 音频播放 / 暂停。视频是抽一帧画在画布上的，播的时候一边播一边重画
认哪些格式浏览器能解码的才算：视频 mp4（H.264）/ webm 最稳，mov 要看里面的编码（ProRes、H.265 之类放不了）； 音频 mp3 / m4a / wav / ogg 都行
放不了会怎样底栏直接说原因（「放不了这个视频（这个文件播不了）」）， 节点上也会写「视频读不出来」—— 不会假装在播
安全的源才给打开javascript: 之类一律拦掉 —— 这个源会被拿去 window.open，不拦就是个执行脚本的入口
把图片拖进窗口落在鼠标松开的位置。★ 会自动复制一份到 user/， 文档里只记文件名（比内嵌省地方得多）。第一次会问你要一次 user/ 文件夹的权限， 之后全自动；不给权限就退回内嵌
拖进来的文件超过 5MB先弹一次提醒（会复制一份，原文件不动）。 勾上「以后不再提示」就不再问
拖它的右下角改宽度：图片按原始比例、视频按 16:9 起算、音频 / 网页 / 文件是一条固定高的条
双击表格格子改内容；格子里的字也能写 {变量}
表格的加减号选中它，行的右侧 / 列的下方各有一对；删有数据的要先确认
双击嵌入节点进去编辑（改的是副本，原文件不受影响）
里面按 Esc回到外层

— 提示语的规范 —
一律以 * 开头底栏那一行就是「刚发生了什么」
一句话，不超过 28 字不塞教程 —— 教程在本页
改动类必须报名字改谁就说谁：节点用正文，分组用标题，连线写「起点 → 终点」
改内容的也要记改名 / 改值 / 改格子 / 改样式 / 改形状 / 改尺寸，一样要报名字
外观节点（程序节点）也算它自己的参数、以及它作用到哪个目标上，都要报出来
不写快捷键快捷键在本页的「快捷键一览」里
